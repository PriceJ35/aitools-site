What Is Cursor?

Cursor is an AI-first code editor forked from VS Code that deeply understands your entire codebase. It features intelligent tab completion, multi-file AI editing, chat with codebase context, and natural language coding. Built by Anysphere, it's become the go-to editor for developers who want AI deeply integrated into their workflow.

Key Features

  • Intelligent Tab Completion — Predicts and completes code across multiple lines with context awareness
  • Multi-file Editing — AI can read and modify multiple files simultaneously
  • Codebase Chat — Ask questions about your entire project with full context
  • Natural Language Coding — Describe what you want in plain English and Cursor writes the code
  • Cmd+K Inline Editing — Highlight code and instruct AI to modify it inline
  • @ Codebase Referencing — Reference specific files, docs, or web in your prompts
