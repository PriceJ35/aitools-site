What Is Perplexity?

Perplexity is an AI search engine that provides direct, cited answers to questions by searching the web in real-time. Unlike traditional search engines that return links, Perplexity synthesizes information from multiple sources into clear, referenced answers. It supports follow-up questions, file uploads, and focused search modes for academic, writing, and math tasks.

Key Features

  • Real-time Web Search — Searches the live web and synthesizes answers with citations
  • Source Citations — Every claim linked to its source for verification
  • Focus Modes — Specialized search for Academic, Writing, Math, and YouTube
  • File Analysis — Upload PDFs, images, and documents for AI analysis
  • Collections — Save and organize research threads into reusable knowledge bases
  • Pro Search — Multi-step reasoning that breaks complex questions into sub-queries
